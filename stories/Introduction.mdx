## Principles

- **Consistent.** Every component reads from the same tokens, so spacing, color and type never drift.
- **Accessible.** Interactive components use semantic elements, visible focus rings and Headless UI where behavior is complex.
- **Themeable.** Dark mode works through the Tailwind `dark` class. Use the **Dark mode** control in each story to preview it.
- **Documented.** Each page has a description, usage guidance, a props table and live controls.

## How to explore

1. Open any component and read the **Docs** tab for guidance and the props table.
2. Switch to a story and use the **Controls** panel to change props live.
3. Use the **Accessibility** panel to check contrast and ARIA issues.
4. Open the **Design** panel to compare the component with its Figma source.
